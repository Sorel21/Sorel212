# Soare Andrei — Portfolio

Personal portfolio website for **robotics, automation, mechanical design and visual media**.

## Live site

This repository is ready for GitHub Pages.

To publish it:

1. Open **Settings → Pages**
2. Under **Build and deployment**, choose **Deploy from a branch**
3. Select **main** and **/(root)**
4. Save

Because this repository is named `Sorel212`, GitHub Pages will publish it as a project site under the account domain.

## Stack

- HTML
- CSS
- Vanilla JavaScript
- No framework
- No build step
- Fully responsive
- Reduced-motion support

## Structure

- `index.html` — content and semantic structure
- `styles.css` — visual system, responsive layout and animations
- `script.js` — reveal effects, navigation, pointer spotlight and scroll progress
- `favicon.svg` — custom SA favicon

Built to stay lightweight and easy to evolve.
